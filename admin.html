Conectar con GitHub

Necesitás un token de acceso personal de GitHub con permiso de escritura solo sobre este repositorio. Se guarda únicamente en este navegador, nunca se envía a ningún otro lado.

Cómo crear el token

Personal Access Token de GitHub

  1. Andá a github.com → foto de perfil (arriba a la derecha) → Settings.
  2. En el menú de la izquierda, al final, Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Ponele un nombre (ej: "admin-portfolio"). En Repository access, elegí Only select repositories y seleccioná tu repo del portfolio.
  5. En Permissions → Repository permissions, buscá Contents y ponelo en Read and write.
  6. Generá el token y copialo (empieza con github_pat_). Solo se muestra una vez, pegalo acá arriba.
